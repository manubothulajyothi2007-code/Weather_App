# 🌦️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript. This application fetches real-time weather information using the *OpenWeatherMap API*.
---
## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays temperature in Celsius
- ☁️ Shows current weather condition
- 💧 Displays humidity
- 💨 Displays wind speed
- 📱 Responsive and clean user interface
- ⚠️ Error message for invalid city names
---
## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Get a free API key from OpenWeatherMap.
3. Open `WeatherApp.js`.
4. Replace:

```javascript
const apiKey = "YOUR_API_KEY";
```
with your own API key.

5. Save the file.
6. Open `index.html` in your browser.
